A carousel block built on CSS scroll snap, scroll buttons and scroll markers.

== Description ==

Adds two blocks:

* Carousel (hlb/carousel): the track and every control setting.
* Slide (hlb/carousel-slide): holds any blocks.

In browsers that support CSS scroll buttons and scroll markers (Chrome and Edge 135+), the arrows and markers are generated by CSS. Elsewhere a small script shows equivalent buttons and markers. Without JavaScript the track still scrolls and snaps.

Autoplay is optional. A pause button can be shown for it (off by default). Autoplay pauses on hover, stops on keyboard focus or interaction, and does not start when reduced motion is requested.

Styling is driven by CSS custom properties on .wp-block-hlb-carousel, so themes can restyle controls without overriding selectors:

--hlb-carousel-gap, --hlb-carousel-control-gap, --hlb-carousel-button-size, --hlb-carousel-button-background, --hlb-carousel-button-hover-background, --hlb-carousel-button-border, --hlb-carousel-icon-prev, --hlb-carousel-icon-next, --hlb-carousel-icon-prev-hover, --hlb-carousel-icon-next-hover, --hlb-carousel-icon-size, --hlb-carousel-marker-size, --hlb-carousel-marker-gap, --hlb-carousel-marker-color, --hlb-carousel-marker-active-color, --hlb-carousel-focus-color.

== Development ==

npm install && npm run build. Source is in src/, output in build/.

The built files in build/ are committed, so the plugin works when installed with Composer (hlebarovcom/hlb-carousel) without a build step. Run npm run build before tagging a release.
